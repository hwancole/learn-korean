You've learned to talk about what [happened](/learn-korean/en/korean-past-tense/) and what [will happen](/learn-korean/en/korean-future-tense/). But a lot of real conversation is less certain than that: "I think it's going to rain", "It seems like he left", "I don't think I can make it". In Korean, all of these use one very common pattern: **것 같아요**.

> **Quick answer:** Put a modifier form of the verb or adjective before **것 같아요** (*geot gatayo*). For an action happening now, use **-는**: 비가 **오는** 것 같아요 (*biga oneun geot gatayo*, "It seems to be raining"). For something that already happened, use **-(으)ㄴ**: 비가 **온** 것 같아요 ("It seems it rained"). For a guess about the future, use **-(으)ㄹ**: 비가 **올** 것 같아요 ("I think it's going to rain"). Adjectives take **-(으)ㄴ** in the present: **비싼** 것 같아요 ("I think it's expensive"). "I think so" is **그런 것 같아요** and "I don't think so" is **아닌 것 같아요**. For a firm opinion, use **-다고 생각해요**.

The -는 and -(으)ㄴ forms are the same modifiers you saw in [when](/learn-korean/en/korean-when/) (-(으)ㄹ 때) and [before and after](/learn-korean/en/korean-before-after/) (-(으)ㄴ 후에), so if those felt comfortable, this lesson reuses the same skill. Romanization follows the Revised Romanization system, which spells words the way they sound.

## What 것 같아요 literally means

**것** (*geot*) means "thing" or "fact", and **같다** (*gatda*) means "to be like" or "the same". So 비가 오는 것 같아요 is literally "It is like the fact that rain is falling." In natural English that becomes "It seems to be raining" or "I think it's raining."

Two things make this pattern so useful:

1. **It expresses a guess.** You're not 100% sure, so you hedge.
2. **It softens what you say.** Koreans often use 것 같아요 even when they *are* sure, simply to sound less blunt. 이게 더 좋은 것 같아요 ("I think this one is better") sounds gentler than 이게 더 좋아요 ("This one is better").

**Pronunciation:** 같아요 is pronounced [가타요], so it's romanized *gatayo*. In fast speech, 것 같아요 often sounds like [거까타요], and in casual writing you'll see it spelled **거 같아요**.

## The three tenses: -는, -(으)ㄴ, -(으)ㄹ

With action verbs, the modifier you choose tells the listener *when* the thing you're guessing about happens.

| Time of the guess | Ending | Example | Romanization | Meaning |
|---|---|---|---|---|
| Happening now | -는 것 같아요 | 비가 오는 것 같아요 | biga oneun geot gatayo | It seems to be raining |
| Already happened | -(으)ㄴ 것 같아요 | 비가 온 것 같아요 | biga on geot gatayo | It seems it rained |
| Will happen | -(으)ㄹ 것 같아요 | 비가 올 것 같아요 | biga ol geot gatayo | I think it's going to rain |

### How to form each one

- **-는**: add it to any verb stem, with or without a final consonant. 가다 → 가**는**, 먹다 → 먹**는**.
- **-(으)ㄴ**: stems ending in a vowel add **-ㄴ** (가다 → **간**). Stems ending in a consonant add **-은** (먹다 → 먹**은**).
- **-(으)ㄹ**: stems ending in a vowel add **-ㄹ** (가다 → **갈**). Stems ending in a consonant add **-을** (먹다 → 먹**을**).

| Verb | Now (-는) | Past (-(으)ㄴ) | Future (-(으)ㄹ) |
|---|---|---|---|
| 가다 (to go) | 가는 (ganeun) | 간 (gan) | 갈 (gal) |
| 오다 (to come) | 오는 (oneun) | 온 (on) | 올 (ol) |
| 하다 (to do) | 하는 (haneun) | 한 (han) | 할 (hal) |
| 자다 (to sleep) | 자는 (janeun) | 잔 (jan) | 잘 (jal) |
| 먹다 (to eat) | 먹는 (meongneun) | 먹은 (meogeun) | 먹을 (meogeul) |
| 읽다 (to read) | 읽는 (ingneun) | 읽은 (ilgeun) | 읽을 (ilgeul) |
| 늦다 (to be late) | 늦는 (neunneun) | 늦은 (neujeun) | 늦을 (neujeul) |

Some everyday sentences:

- **민수 씨가 자는 것 같아요.** (*Minsu ssiga janeun geot gatayo.*) "I think Minsu is sleeping."
- **민수 씨가 벌써 집에 간 것 같아요.** (*Minsu ssiga beolsseo jibe gan geot gatayo.*) "It seems Minsu already went home."
- **조금 늦을 것 같아요.** (*Jogeum neujeul geot gatayo.*) "I think I'll be a little late."

That last one is probably the most useful sentence in this whole lesson. Send it to a friend when you're running behind.

## Adjectives: -(으)ㄴ 것 같아요

Descriptive verbs (adjectives) are simpler: they don't use -는. For a present-tense impression, use **-(으)ㄴ**. For a guess about the future, use **-(으)ㄹ**.

| Adjective | Now (-(으)ㄴ) | Example | Meaning |
|---|---|---|---|
| 비싸다 (expensive) | 비싼 (bissan) | 좀 비싼 것 같아요 | I think it's a bit expensive |
| 바쁘다 (busy) | 바쁜 (bappeun) | 요즘 바쁜 것 같아요 | You seem busy these days |
| 좋다 (good) | 좋은 (joeun) | 이게 더 좋은 것 같아요 | I think this one is better |
| 작다 (small) | 작은 (jageun) | 신발이 작은 것 같아요 | I think the shoes are small |
| 피곤하다 (tired) | 피곤한 (pigonhan) | 피곤한 것 같아요 | You look tired / I think I'm tired |

| Adjective | Future guess (-(으)ㄹ) | Romanization | Meaning |
|---|---|---|---|
| 춥다 (cold) | 내일 추울 것 같아요 | naeil chuul geot gatayo | I think it'll be cold tomorrow |
| 바쁘다 (busy) | 다음 주에 바쁠 것 같아요 | daeum jue bappeul geot gatayo | I think I'll be busy next week |
| 재미있다 (fun) | 이 영화 재미있을 것 같아요 | i yeonghwa jaemiisseul geot gatayo | This movie looks like it'll be fun |

Watch out for the most common mistake: with adjectives, **-(으)ㄴ is present, not past.** 비싼 것 같아요 means "I think it *is* expensive." Using -는 with an adjective (비싸는 것 같아요) is wrong.

### 있다 and 없다 take -는

Words ending in **있다** and **없다**, including 맛있다 (tasty) and 재미있다 (fun), take **-는** in the present even though they feel like adjectives.

- **맛있는 것 같아요.** (*Masinneun geot gatayo.*) "I think it's tasty."
- **집에 아무도 없는 것 같아요.** (*Jibe amudo eomneun geot gatayo.*) "It seems nobody's home."

## Nouns: -인 것 같아요

After a noun, use **인** (from 이다, "to be") for the present and **일** for a guess.

- **학생인 것 같아요.** (*Haksaengin geot gatayo.*) "I think he's a student."
- **저 사람은 한국 사람일 것 같아요.** (*Jeo sarameun hanguk saramil geot gatayo.*) "That person is probably Korean."

The negative of 이다 is 아니다, which gives you two essential phrases:

| Korean | Romanization | Meaning |
|---|---|---|
| 그런 것 같아요 | geureon geot gatayo | I think so / It seems so |
| 아닌 것 같아요 | anin geot gatayo | I don't think so / It doesn't seem right |
| 그럴 것 같아요 | geureol geot gatayo | It'll probably be like that |
| 아닐 것 같아요 | anil geot gatayo | It probably won't be |

## Talking about the past more precisely

Two more forms are very common once you're past the basics.

**-았/었을 것 같아요** guesses about something in the past, often to show sympathy:

- **힘들었을 것 같아요.** (*Himdeureosseul geot gatayo.*) "That must have been hard."
- **많이 놀랐을 것 같아요.** (*Mani nollasseul geot gatayo.*) "You must have been really surprised."

**-았/었던 것 같아요** describes a past impression you're a little unsure about:

- **그 식당은 좀 비쌌던 것 같아요.** (*Geu sikdangeun jom bissatdeon geot gatayo.*) "I think that restaurant was a bit expensive."

## Irregular verbs

The usual irregular rules apply, because -(으)ㄴ and -(으)ㄹ start with a vowel sound or attach directly.

| Type | Verb | Now | Past / adjective | Future |
|---|---|---|---|---|
| ㄹ drops | 살다 (to live) | 사는 (saneun) | 산 (san) | 살 (sal) |
| ㄹ drops | 멀다 (far) | — | 먼 (meon) | 멀 (meol) |
| ㅂ → 우 | 덥다 (hot) | — | 더운 (deoun) | 더울 (deoul) |
| ㅂ → 우 | 맵다 (spicy) | — | 매운 (maeun) | 매울 (maeul) |
| ㄷ → ㄹ | 듣다 (to listen) | 듣는 (deunneun) | 들은 (deureun) | 들을 (deureul) |
| ㅅ drops | 낫다 (better) | — | 나은 (naeun) | 나을 (naeul) |

So: **이거 좀 매운 것 같아요** (*Igeo jom maeun geot gatayo*, "I think this is a bit spicy") and **여기서 좀 먼 것 같아요** (*Yeogiseo jom meon geot gatayo*, "I think it's a bit far from here").

## Negative sentences

You can make the verb negative with [안 or 못](/learn-korean/en/korean-negation/) before adding 것 같아요:

- **오늘은 비가 안 올 것 같아요.** (*Oneureun biga an ol geot gatayo.*) "I don't think it'll rain today."
- **내일은 못 갈 것 같아요.** (*Naeireun mot gal geot gatayo.*) "I don't think I can go tomorrow."

The second sentence is the standard polite way to turn down an invitation. It sounds much softer than 못 가요 ("I can't go").

## 것 같아요 vs -다고 생각해요

English "I think" covers both guesses and opinions. Korean splits them.

- **것 같아요** is for guesses, impressions and softened statements. It's what you'll hear most in daily conversation.
- **-다고 생각해요** (*-dago saenggakhaeyo*) is for a considered opinion, like in a discussion or an essay. Adjectives take -다고 (좋다고 생각해요, *jotago saenggakhaeyo*, "I think it's good"), action verbs take -ㄴ다고/-는다고 (간다고, 먹는다고), and nouns take -(이)라고 (학생이라고).

| Sentence | Nuance |
|---|---|
| 이 방법이 더 좋은 것 같아요. | I think this way is better. (soft, conversational) |
| 이 방법이 더 좋다고 생각해요. | In my view, this way is better. (firm, deliberate) |

## 것 같아요 vs -(으)ㄹ 거예요 vs -아/어 보여요

| Pattern | Use | Example |
|---|---|---|
| -(으)ㄹ 거예요 | A confident prediction or plan | 비가 올 거예요. "It will rain." |
| -(으)ㄹ 것 같아요 | A softer guess | 비가 올 것 같아요. "I think it'll rain." |
| -아/어 보여요 | How something looks from the outside (adjectives) | 맛있어 보여요. "It looks tasty." |

Use 보여요 when you're describing appearance only. Use 것 같아요 when you're drawing a conclusion, even from what you see: dark clouds, so 비가 올 것 같아요.

## Formal and casual versions

The ending changes with the [speech level](/learn-korean/en/korean-speech-levels/), while 것 stays the same.

| Speech level | Form | Example |
|---|---|---|
| Formal (news, presentations) | 것 같습니다 (geot gatseumnida) | 내일 비가 올 것 같습니다. |
| Polite (everyday) | 것 같아요 (geot gatayo) | 내일 비가 올 것 같아요. |
| Casual (friends) | 것 같아 / 거 같아 (geot gata / geo gata) | 내일 비 올 것 같아. |

## FAQ

**Is 것 같아요 polite?** Yes. It's the polite -아요 ending on 같다. With friends, drop 요: **것 같아** or **거 같아**. In formal speech, use **것 같습니다**.

**Why do Koreans say 것 같아요 about their own feelings?** It softens the statement. **배가 고픈 것 같아요** (*Baega gopeun geot gatayo*) literally means "I think I'm hungry", but often it just means "I'm kind of hungry." Some teachers and commentators point out that it gets overused, especially for things you clearly know, like 맛있는 것 같아요 while you're eating. In everyday speech it's extremely common.

**What's the difference between 같아요 and 같은?** 같아요 ends a sentence ("it seems"). 같은 modifies a noun and means "like" or "the same": **꿈 같은 날** ("a dreamlike day"), **같은 반** ("the same class").

**Can I use 것 같아요 to ask a question?** Yes, with a rising tone: **괜찮을 것 같아요?** (*Gwaenchaneul geot gatayo?*) "Do you think it'll be OK?"

**What's next?** Combine this with [want to](/learn-korean/en/korean-want-to/) and [can and can't](/learn-korean/en/korean-can-cant/) to accept or decline plans politely: 가고 싶은데 못 갈 것 같아요, "I want to go, but I don't think I can."
